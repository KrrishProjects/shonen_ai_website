Security

Last updated: 29 May 2026

This page explains the security practices and safety guidelines for Shonen AI.

1. Account security

Shonen AI may use Firebase Authentication for login and account management. Users should keep their Google account, email account, and device secure.

2. Backend security

Shonen AI backend services are designed to use environment variables for sensitive API keys and configuration values. API keys and secrets should not be placed directly inside the public app code.

3. Data protection

We use reasonable security measures such as authentication, secure backend configuration, and access controls where applicable. However, no app or online service can guarantee complete security.

4. Upload safety

Users should avoid uploading highly sensitive personal, financial, legal, medical, or confidential information. Uploaded images, PDFs, and prompts may be processed by backend services and AI providers to deliver app features.

5. AI safety

AI responses may be wrong, incomplete, or unsafe if used without judgment. Users should verify important information and should not rely on AI responses for emergencies or critical decisions.

6. Reporting security issues

If you find a security issue, bug, account problem, payment issue, or data concern, please report it responsibly by email.
